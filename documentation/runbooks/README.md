# Runbooks

Procedures Sam runs step by step.

- [Manual install and test](/documentation/runbooks/manual_install_and_test.md) — build the
  artifacts, install them by hand into Arma and TeamSpeak, and run the live checks.

Each step has one command and an expected result. No step copies files into the game or TeamSpeak
on Sam's behalf. A runbook changes in the same commit as a command or file name it cites.
