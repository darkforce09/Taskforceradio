# Bug fixes

Every bug in the original C++ that the Rust port fixes on purpose (decision D3: fix all bugs, keep
wire formats compatible). Each entry names the original code, what it does, what the port does
instead, the crate that owns the fix, the milestone that lands it, and the test that pins it. The
Test column says "pending" until the owning milestone names the test; M8 closes the catalogue only
when every row names one.

The references and behaviours come from the behaviour specs:
[0.9 plugin](/documentation/program/behaviour_specs/tfar_0_9_plugin.md),
[1.0 plugin](/documentation/program/behaviour_specs/tfar_1_0_plugin.md) and
[extensions](/documentation/program/behaviour_specs/extensions.md). Ids are stable: a fixed entry
keeps its id, and a new bug takes the next free one.
