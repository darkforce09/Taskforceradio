# Standards

The rules the code and documents follow, in three pages. [CLAUDE.md](/CLAUDE.md) states the laws in a
paragraph each; these pages give the detail, and every rule with a checker names it.

- [Code and documentation](/documentation/standards/code_and_documentation.md) — language, manifests,
  errors and panics, unsafe and FFI, the audio-thread rules, names, comments, documents, commits.
- [Testing](/documentation/standards/testing.md) — what is tested, where tests live, what never gets a
  test.
- [Crate boundary rules](/documentation/standards/crate_boundary_rules.md) — tiers, the category edge
  matrix, the external-crate firewalls, the unsafe allow-list, features.
